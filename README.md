# Laptop Price Prediction 💻

A Machine Learning web application built using Python and Streamlit to predict the price of a laptop based on its configuration (Brand, RAM, CPU, GPU, OS, Weight, Touchscreen, IPS Display, etc.).

## 🚀 Features
* Predicts laptop prices accurately based on user specifications.
* Clean and interactive UI built with **Streamlit**.
* Uses a Trained Machine Learning Pipeline (`pipe.pkl`) for prediction.

## 🛠️ Tech Stack Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn
* **Web Framework:** Streamlit
